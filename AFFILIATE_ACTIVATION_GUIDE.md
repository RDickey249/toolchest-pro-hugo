## ⚡ Instant Activation Process

When you get approved for an affiliate program:

### Option 1: Single Tool Activation
```bash
cd ~/toolchest-pro-hugo
python3 scripts/activate_affiliate_program.py --tool shopify --affiliate-url "https://www.shopify.com/partners/YOUR_ID" --commission "Revenue Share"
```

### Option 2: Batch Activation (Recommended)
1. Create a file with all your approved URLs:
```bash
# affiliate_urls.txt
shopify,https://www.shopify.com/partners/YOUR_ID,$58
bigcommerce,https://www.bigcommerce.com/partners/YOUR_ID,200%
webflow,https://webflow.com/partners/YOUR_ID,50%
```

2. Activate all at once:
```bash
python3 scripts/activate_affiliate_program.py --batch-activate affiliate_urls.txt
```

### Option 3: Check Current Status
```bash
python3 scripts/activate_affiliate_program.py --status
```
