## Key Features

• **Unlimited Input Sources** - Support for multiple cameras, microphones, computer desktops, web feeds, and media files for complex production environments
• **Professional Video Switching** - Real-time cutting between sources with broadcast-quality transitions, titles, and graphics
• **Advanced Graphics Package** - Lower thirds, title cards, virtual sets, and customizable templates for polished professional presentations
• **Comprehensive Audio Mixing** - Professional mixing console with EQ, compressor, and limiter effects ensuring broadcast-quality sound
• **Multi-Destination Streaming** - Simultaneous streaming to multiple platforms enabling broad audience reach across various services
• **Professional Recording Capabilities** - Capture isolated sources, program output, and multiple formats simultaneously for post-production workflows
• **Hardware Integration Support** - Seamless connectivity with hardware switchers, teleprompters, and external graphics systems for scalable productions
• **NewTek NDI Network Production** - Network-based video workflows that reduce cable complexity in multi-camera professional setups
