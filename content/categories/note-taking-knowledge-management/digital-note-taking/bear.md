## Key Features

• **Elegant markdown editor** - Beautiful, distraction-free writing interface with live preview and syntax highlighting
• **Flexible hashtag organization** - Nested tags with intelligent auto-completion and hierarchical structure
• **Powerful cross-note linking** - Wiki-style internal links with backlink navigation and relationship mapping
• **Stunning visual themes** - Multiple carefully crafted themes optimized for different lighting and preferences
• **Seamless Apple ecosystem sync** - Real-time synchronization across Mac, iPhone, and iPad with conflict resolution
• **Advanced export capabilities** - Export to PDF, Word, HTML, and other formats with beautiful formatting preservation
• **Immersive focus mode** - Distraction-free writing environment that highlights current paragraph or sentence
• **Rich media integration** - Support for images, attachments, and formatting within markdown workflow
